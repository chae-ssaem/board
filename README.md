# 우리 반 칠판 — 설치 안내서

교실 전자칠판에 띄워 두는 대시보드와 리모컨이에요.
시간표(컴시간 자동 연동), 급식, 학사일정, 날씨, 호출, 체크 명단, 알림판, 타이머, 랜덤 뽑기, 소음 신호등이 들어 있어요.

```
uri-ban-chilpan/
├─ index.html        전자칠판 화면 (처음 설정 마법사 포함)
├─ remote.html       리모컨
├─ icons/            앱 아이콘 (채쌤보드 · 채쌤보드 리모컨)
├─ manifest-*.webmanifest, sw.js   앱으로 설치하기
├─ common.js         두 화면이 같이 쓰는 기능
├─ api/              컴시간·NEIS 중계 (Vercel에서 실행)
├─ firestore.rules   파이어베이스 보안 규칙
└─ package.json
```

## 누가 무엇을 하나요?

| | 채쌤(만든 사람) — 처음 한 번 | 다른 선생님 — 각자 |
|---|---|---|
| ① 사이트 올리기 (Vercel) | ✅ | ✗ (채쌤 주소를 그대로 씀) |
| ② 파이어베이스 만들기 | ✅ | ✅ |
| ③ 칠판에서 처음 설정 | ✅ | ✅ |
| ④ 폰으로 QR 찍기 | ✅ | ✅ |

학생 이름과 반 자료는 **각 선생님의 파이어베이스에만** 저장돼요. 채쌤의 Vercel 중계는 시간표·급식만 가져다주고, 학생 정보는 거치지 않아요.

## ① 사이트 올리기 (채쌤만, 처음 한 번 · 10분)

GitHub과 Vercel 무료 계정이 필요해요. 카드 등록은 없어요.

1. **GitHub**(github.com)에 로그인 → 오른쪽 위 `+` → **New repository**
   - 이름: `uri-ban-chilpan` (아무거나 괜찮아요) → **Create repository**
   - 화면의 **uploading an existing file** 링크를 눌러 이 폴더의 파일을 **모두** 끌어다 놓고 **Commit changes**
     (`node_modules` 폴더는 올리지 않아도 돼요)
2. **Vercel**(vercel.com) → **Continue with GitHub**로 가입
3. **Add New… → Project** → 방금 만든 저장소 옆 **Import** → 설정은 그대로 두고 **Deploy**
4. 1~2분 뒤 `https://uri-ban-chilpan.vercel.app` 같은 주소가 생겨요. 이게 **우리 반 칠판 주소**예요.
5. 잘 됐는지 확인: 브라우저에서 `주소/api/search?q=우리학교이름` 을 열어 학교 목록이 나오면 성공!

### (선택) NEIS 인증키 넣기 — 추천

인증키가 없으면 NEIS가 한 번에 5줄만 줘서, 학사일정이 많은 주에는 일부가 빠지고,
컴시간이 막혔을 때 쓰는 NEIS 시간표 대체 기능도 제대로 안 돼요.

1. open.neis.go.kr → 회원가입 → **마이페이지 → 인증키 신청** (바로 발급돼요)
2. Vercel 프로젝트 → **Settings → Environment Variables**
   - Name: `NEIS_KEY` / Value: 발급받은 키 → **Save**
3. **Deployments** 탭 → 맨 위 배포의 `⋯` → **Redeploy**

## ② 파이어베이스 만들기 (선생님마다 · 10분)

호출·체크 명단 등이 칠판과 폰 사이에 실시간으로 오가는 저장소예요. 무료(Spark) 요금제로 충분해요.

1. console.firebase.google.com → **프로젝트 추가** → 이름 입력 (예: `our-class-board`) → Google 애널리틱스는 꺼도 돼요 → 만들기
2. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` → **프로덕션 모드**로 시작
3. Firestore 화면 위쪽 **규칙** 탭 → 안에 있는 글을 모두 지우고 `firestore.rules` 파일 내용을 통째로 붙여 넣기 → **게시**
4. 왼쪽 위 톱니 → **프로젝트 설정** → 아래 **내 앱**에서 `</>`(웹) 아이콘 → 앱 이름 입력 → **앱 등록**
5. 화면에 나온 코드 중 `const firebaseConfig = { … };` 부분을 복사해 두세요. (나중에 프로젝트 설정 → 내 앱 → **SDK 설정 및 구성 → 구성**에서 다시 볼 수 있어요)

## ③ 전자칠판에서 처음 설정 (5분)

1. 전자칠판의 크롬(또는 엣지)에서 **우리 반 칠판 주소**를 열어요.
2. **처음 설정하기**를 누르고 마법사를 따라가요.
   1. **파이어베이스**: 복사해 둔 `firebaseConfig`를 붙여 넣기
   2. **학교·반**: 학교 이름 검색 → 컴시간 학교와 NEIS 학교 고르기(이름이 같으면 자동으로 골라져요) → 학년·반
   3. **학생 명단**: 엑셀이나 나이스에서 `번호 · 이름` 두 칸을 복사해 붙여 넣기
      셋째 칸에 생일(예: `김채아 9/14`)을 넣으면 아침 화면에 생일 축하가 떠요. 건너뛰고 나중에 폰에서 넣어도 돼요.
3. 마지막 화면에 **QR**이 떠요.

> 먼저 둘러보고 싶으면 첫 화면의 **체험해 보기**를 누르세요. 예시 데이터로 모든 기능을 눌러 볼 수 있어요.
> (주소 뒤에 `?demo`를 붙여도 돼요)

## ④ 리모컨 연결

- 칠판의 QR을 폰 카메라로 찍으면 리모컨이 열려요. 폰에서는 아무것도 입력하지 않아도 돼요.
- 자주 쓰려면 브라우저 메뉴의 **홈 화면에 추가**를 눌러 두세요. 앱처럼 열려요.
- QR은 나중에도 칠판 **왼쪽 아래 톱니 → 리모컨 연결 (QR)**에서 다시 볼 수 있어요.
- **QR과 연결 주소는 우리 반 칠판의 열쇠예요.** 학생이 찍지 않도록, 선생님만 볼 때 띄워 주세요.

## 앱으로 설치하기 (아이콘 만들기)

바로가기가 아니라 **채쌤보드 아이콘**이 생기고, 열면 주소창 없이 앱처럼 떠요.

| 기기 | 방법 | 생기는 이름 |
|---|---|---|
| 윈도우 전자칠판 (크롬·엣지) | 칠판 주소를 열고 주소창 오른쪽 **설치(⊕) 아이콘** → 설치 | 채쌤보드 (바탕화면·작업 표시줄·시작 메뉴) |
| 아이폰 | 리모컨을 Safari로 열고 **공유 → 홈 화면에 추가** | 채쌤보드 리모컨 |
| 안드로이드폰 | 리모컨을 크롬으로 열고 **⋮ → 앱 설치**(또는 홈 화면에 추가) | 채쌤보드 리모컨 |

- 아이폰은 반드시 **QR을 찍어 연결된 상태에서** 홈 화면에 추가해 주세요. 그래야 홈 화면 앱에서도 바로 연결돼요.
- 앱으로 설치해도 업데이트는 자동이에요. GitHub에 새 파일을 올리면 다음에 열 때 바뀐 화면이 떠요.

## 매일 쓰는 법

**아침에 칠판을 켜면 화면을 한 번 눌러 주세요.** 브라우저는 한 번 눌러야 호출 소리를 낼 수 있어요.

| 리모컨 탭 | 하는 일 |
|---|---|
| 홈 | 지금 칠판 화면 확인, 타이머·뽑기·소음 신호등·칭찬 별, 진행 중인 체크 명단 |
| 호출 | 이름 고르기 → 장소 또는 **✎ 직접 쓰기**("점심시간에 교무실 들러 주세요"처럼 문장 그대로, 이름을 안 고르면 반 전체에게) → 소리(무음 / 딩동 / 딩동+음성) → **칠판에 띄우기**. 학생이 칠판에서 '지금 갈게요!'를 누르면 폰에 ✓가 떠요 |
| 명단 | 등교 체크·가정통신문 등 체크 명단 켜기/마감, 지난 기록과 안 낸 학생 복사 |
| 알림판 | 주번('다음 차례'를 누르면 번호 순서대로 다음 두 명이 바로 주번이 돼요), 알림·준비물, 오늘의 질문, 청소 구역, 1인1역, 하교 체크리스트, 우리 반 일정(`11/17 일정 국어 수행평가`, `11/18 준비물 체육복`), D-day |
| 설정 | 학생 명단, 내 이름(호출에 표시), 장소 목록, 칠판에 보이기(오늘의 질문·칭찬 별·1인1역 켜고 끄기), 자동 화면 시각, 칭찬 별 목표, 연결 주소 |

**칠판에서 바로 쓰기** — 칠판 오른쪽 포스트잇 탭(타이머 · 뽑기 · 소음)을 누르면 메모지가 펼쳐져요. 폰 없이 칠판에서 바로 시작하고, 가운데에 뜬 화면은 '닫기'로 내릴 수 있어요.

**시간에 따라 칠판이 저절로 바뀌어요** (시간은 컴시간 교시 시각 기준)
- 아침 시작 시각 ~ 1교시 전: 오늘의 질문 + 생일 축하 + 등교 체크(자동으로 켜지고, 1교시가 되면 기록으로 저장)
- 쉬는 시간: 다음 수업까지 남은 시간, 이동 교실, 챙길 것
- 마지막 교시 뒤: 하교 전 체크리스트

## 이럴 땐 이렇게

| 증상 | 해결 |
|---|---|
| 마법사 마지막에 "저장을 막았어요" | ②-2(데이터베이스 만들기)와 ②-3(규칙 게시)을 했는지 확인 |
| 시간표가 안 나오거나 이상해요 | 컴시간이 구조를 바꾼 경우가 많아요. 아래 '컴시간이 바뀌었을 때'를 따라 해 주세요. NEIS 인증키를 넣어 두면 그동안 NEIS 시간표로 대신 보여 줘요 |
| 호출 소리가 안 나요 | 칠판 화면을 한 번 눌렀는지, 칠판 볼륨을 확인. 음성은 칠판에 한국어 음성(TTS)이 있어야 해요 |
| 소음 신호등이 '마이크를 쓸 수 없어요' | 칠판 브라우저 주소창 왼쪽 자물쇠 → 마이크 **허용**. 칠판에 마이크가 있어야 해요 |
| 칠판을 새로 설치했어요 | 리모컨 → 설정 → **칠판 연결 주소 복사** → 새 칠판에서 주소 열기 (또는 첫 화면 '이미 만든 칠판 연결하기'에 붙여 넣기) |
| 부담임 선생님도 쓰고 싶어요 | 리모컨 → 설정 → **다른 선생님 폰 연결 주소 복사** |

### 컴시간이 바뀌었을 때 (채쌤)

컴시간은 공식 API가 없어서 `parse-comcigan` 라이브러리로 읽어 와요. 컴시간이 바뀌면 이 라이브러리가 보통 며칠 안에 고쳐져요.

1. GitHub 저장소의 `package.json`을 열고 연필(수정) 버튼
2. `"parse-comcigan": "^1.6.0"`의 숫자를 npmjs.com/package/parse-comcigan 에 나온 최신 버전으로 바꾸기 → **Commit**
3. Vercel이 알아서 다시 배포해요 (1~2분)

## 개인정보와 학년 말 정리

- 학생 번호·이름·생일과 반 자료는 **선생님 본인의 파이어베이스**에만 저장돼요.
- 소음 신호등은 소리 크기만 재고, 녹음하거나 저장하지 않아요.
- 학년이 끝나면 파이어베이스 콘솔 → Firestore → `classes` 아래 우리 반 문서를 지우거나, 프로젝트를 통째로 삭제하면 깨끗이 정리돼요.
- 학교의 개인정보 처리 기준에 따라 이름 대신 번호만 넣어도 잘 작동해요.
